# 003 新增 `replay_pending` 命令

## 现状

P1.4 之后待重放队列会落盘，但前端没有办法触发重放：重启后队列读回来了，
却只能等程序自己重放（现在没有自动重放逻辑）。

## 建议

新增 `replay_pending` 命令，无参数，返回人可读的汇总字符串：

```
重放 3 笔：成功 2 笔，仍挂起 1 笔
```

## 为什么不返回结构化对象

重放结果是"给柜员看的一句话"。结构化 DTO 会引出"每笔的明细要不要展示"
这个更大的界面问题，而 P1.4 的目标只是让队列不再只进不出。
等 P3 做对账界面时，再补 `TxReplayDetail` 类型。

## 影响

- `contracts/ipc-commands.md`、`contracts/fields.json`
- `apps/shell/src-tauri/src/commands.rs`
- `apps/shell/src/api.ts`、交易面板的"重放"按钮

## 风险

命令是同步的：如果挂起笔数很多且主机慢，会阻塞 IPC。
当前柜面单终端挂起量预期是个位数，暂不引入后台任务；超过 20 笔要改成异步。
